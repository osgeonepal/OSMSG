The core counts

Every edit to a map element (a node, way, or relation) is counted by what it did to that element:

  • Created: a brand-new element (its first version).
  • Modified: an existing element that was changed.
  • Deleted: an element that was removed.

Map changes is the sum of created, modified, and deleted. Changesets counts the edit sessions, and Contributors counts the distinct mappers.

Feature breakdowns

Edits are also grouped by what was mapped, using the element's main tag: buildings, highways, waterways, landuse, natural features, amenities, and points of interest. Each shows + created and ~ modified.

Length (km)

For line features, the length shown is the distance of the ways drawn when they were created, added up. Only open lines are measured. Closed shapes (buildings, areas, and closed loops such as roundabouts) have no length, so they show no km. This is why some line features show km and areas do not.

A line can only be measured when the coordinates of all its points are present as it is read. A line drawn onto pre-existing points is skipped, so its kilometres are not counted. The length total is therefore a lower bound and can read below tools that rebuild the full geometry of each way. The gap is larger where new lines connect into existing data, such as city streets.

Hashtags

Hashtags are matched by prefix, so osmnepal also includes osmnepal-project-123 and similar. Add several hashtags to combine them: a changeset that carries any of them is included, and each changeset is counted once even if it uses more than one.

Time window and freshness

All times are in UTC. Past months come from a published dataset that is complete, and the most recent days come from a live feed that updates every few minutes. The Updated label shows how current the live feed is.
